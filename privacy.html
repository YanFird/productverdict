Privacy Policy - AIVR Autopilot

Last updated: 12 October 2026

AIVR Autopilot is a private publishing tool used only by the owner of the Product Verdict YouTube channel.

What the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos to the owner's own channel, set their title, description, tags, thumbnail and publish time, and post comments on those videos.

What is stored

The Google sign-in token is stored only on the owner's own computer and is never shared. The app does not collect, store, sell or share any personal data of other people, and it does not read viewers' data.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
